# Sales Report

A Python application for processing and analyzing sales data.

## About

Sales Report is a project designed to manage product and purchase data, calculate financial results and generate sales reports.

## Features

- CSV data importing
- Data validation
- Revenue and profit calculations
- Sales summaries

*The project is currently under development.*

## Requirements

- Python
- Git (optional, for cloning)

## Download or Clone

**Option 1: Download**

Download the repository as a ZIP file using the **Code → Download ZIP** button on GitHub, then extract the files.

**Option 2: Clone**

Clone the repository using Git:

```bash
git clone https://github.com/Nero-Works/SalesReport.git
```

## How to Run

1. Open the project folder.
2. Run the application:

```bash
python SalesReport.py
```
